## 简短介绍

UTA：用喜欢的日语歌曲学日语。导入自己的音频和 LRC，逐句听读、看假名、查词、校对，再复习没把握的句子。Windows 桌面版，基本学习功能无需 API Key。

下载：https://github.com/CosmerHomura/Japanese-song-learning-website/releases/latest

## 社区发布文案

标题：做了一个用日语歌曲学日语的小工具：逐句听读、假名注音、查词校对

平时听日语歌，想把歌词真正读懂、念清楚，于是基于一个开源项目扩展了 UTA 桌面版。

你可以导入自己的歌曲和带时间轴的 LRC，逐句播放、慢放、看假名、查询日中词义。自动读音或分词不对，可以手动校对、合并或拆分，再重新查词。学过的句子会记录进度，没把握的句子可以留下复习。

基础学习功能在本机运行，不需要 AI Key；AI 校对是可选项，使用自己的供应商账户，可能产生费用。软件不提供歌曲下载。

目前发布了 Windows 10/11 x64 安装版，欢迎试用并反馈哪里不好用。当前安装包未签名，请确认从项目的 GitHub Release 获取。

下载：https://github.com/CosmerHomura/Japanese-song-learning-website/releases/latest

源码与来源说明：https://github.com/CosmerHomura/Japanese-song-learning-website

## 30 秒演示视频脚本

- 0–5 秒：歌曲库与进度。字幕：把你自己的日语歌变成学习材料。
- 5–12 秒：打开原创练习，展示假名与逐句播放入口。字幕：听一句，读一句，慢慢练熟。
- 12–20 秒：点击词语，展示右侧词义和读音校对。字幕：不懂就查，读音不对就改。
- 20–26 秒：展示待复习句子。字幕：没把握的句子留下复习。
- 26–30 秒：显示下载地址。字幕：Windows 桌面版，基本功能无需 API Key。

界面截图和无声 GIF 位于 [assets](assets/)。素材采用原创练习文字与示例进度，未使用用户数据。GIF 是界面轮播，不是带声音的视频；录制逐句播放时请自行使用原创或授权音频。
