# 架构评估（2026-10）

当前技术栈为 React/Vite、Electron、FastAPI、SudachiPy/SQLite、IndexedDB 与 Local Storage。保持本地优先，重构不同时替换界面、存储和 API。

## 已完成的模块化

- `src/pages/`：歌曲库和复习页面。
- `useLearningStore`：学习快照读取、更新、协调与持久化；纯函数模块负责不可变更新和歌曲关联数据清理。删除歌曲同步清理其进度、修正、AI 记录和费用，保留其他歌曲及共享词义。
- `useAiSettings`：供应商、模型、Key 和启动后台刷新。
- `useLineAudio`：逐句播放、速度和音频生命周期。
- `useReadingPreferences`：字号、动效偏好和系统减少动态效果监听。
- `src/styles/motion.css`：切页、侧栏、卡片动效。移除重复 CSS / Web Animations 切页实现，关闭动效时也关闭程序触发的平滑滚动。
- 设置、整句解析已有独立组件；LRC 时间、备份、共享解析已有独立工具模块。
- `server/services/artwork.py`：封面检索与匹配。供应商注册表、计费归一化与桌面授权已有独立模块。

## 数据与安全边界

学习记录使用 v2 版本化快照，兼容旧 Local Storage 与旧备份。一次状态更新保留修正、费用等其他字段，避免分散写入互相覆盖。歌曲音频仍在 IndexedDB，跨两种存储的原子事务尚未实现；本轮状态整理不等于完整存储迁移。

桌面管理与付费 API 经受限 IPC 附加会话令牌，服务只监听回环地址。CORS 不代替授权，发布前仍需独立安全审计。歌曲、密钥、生成数据不可进入版本库。

## 验证覆盖

单元测试覆盖快照迁移、关联数据清理、读音、备份、时间轴、授权与封面匹配。`npm run test:ui` 在隔离 Electron 用户目录使用原创示例，验证修正颜色、建议队列入口、选择与取消选择、修正持久化、导航及三种动效模式；阻止外部网络，不调用付费 AI，不读写真实曲库。

这不等于完整发行验证：真实安装、自动升级、付费供应商与复杂导入恢复仍需专项测试。

## 尚待收敛的职责

1. `App.jsx` 仍承接学习页布局、导入/备份和分词校正协调；继续按学习会话、导入恢复拆分，并补取消、失败和恢复场景测试。
2. `server/app.py` 仍有标注、模型目录与 AI 路由；继续抽取标注与模型目录服务，显式传入配置和缓存，保持 API 兼容。
3. 统一迁到 IndexedDB 前，补恢复失败回滚、历史备份测试；长期修正标识采用稳定 token ID 或字符跨度，避免重新分词后下标错位。
4. 干净 Windows 环境验证安装、快捷方式、更新和数据保留。验收期间版本号不变，以构建时间区分产物，定版后再发行。

本轮是可验证的模块化整理，不宣称整个架构重构已经完成。
