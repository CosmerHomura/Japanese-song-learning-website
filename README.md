# UTA · 日语歌词发音学习站

一个面向有一定日语基础的歌词学习网站。把歌曲按 LRC 时间轴拆成逐句练习：先听原声，再看读音、查词义，最后跟唱和校对。

## 原项目来源

本仓库 fork 自 [meilawiet/Japanese-song-learning-website](https://github.com/meilawiet/Japanese-song-learning-website)，感谢原作者提供日语歌曲学习项目。本 fork 在原项目基础上扩展了 Windows 桌面封装、本地词典管理、多供应商 AI、分词校对、学习与复习流程，以及解析共享等功能；并非原作者官方桌面发行版。原项目的版权及许可证声明应继续保留，第三方词典数据另见 [THIRD_PARTY_DATA_NOTICES.md](THIRD_PARTY_DATA_NOTICES.md)。

> 当前版本适合本地运行和邀请朋友试用。歌词、音频和专辑封面可能受版权保护；公开部署前请确保自己拥有相应授权。

## 能做什么

左上角 UTA 标志可返回歌曲库并滚动到页顶。页面标志、网页 favicon 与 Windows 应用图标统一使用“书页与音符”设计。

桌面设置分为“AI 与模型 / 本地词典 / 阅读与动效”三个分类。应用启动后自动在后台刷新当前供应商的模型目录，打开设置无需等待；关闭按钮、点击遮罩和 Esc 均可关闭，后台刷新继续进行。刷新不会覆盖你正在编辑的模型或 Key。字号和动效即时自动保存，AI 配置需要点击“保存 AI 设置”。

- 导入带时间轴的日语 LRC 与歌曲音频；保存前可预览并校对歌词、译文、时间戳和封面。
- 根据每句时间戳播放原声，播放起点提前 0.5 秒；支持 `1× / 0.75× / 0.5× / 0.25×` 慢放。
- 如果 LRC 含中文译文，会在对应日文歌词下显示；每句可切换“已掌握 / 未掌握”，歌曲库同步显示掌握进度。
- 逐句练习模式先隐藏读音和译文，听原声、自行回忆后再揭晓；选“还要再练”的句子自动进入复习清单。
- 用 SudachiPy 生成逐词假名读音；可手动校正，修正结果优先显示。
- 提供原文、假名、遮住读音三种学习模式。
- 本地日中词典提供常用中文释义和词形信息；纯假名同形词会按词性优先消歧。
- 鼠标拖选歌词片段后可请求 AI 语境讲解；AI 只给建议，不会自动修改学习内容。
- 歌曲导入与 AI 解析分开：保存歌曲后即可听读，学习页可按需生成解析或导入共享解析。
- AI 复核整首歌曲中可能不合理的读音，并逐条供用户确认。
- 桌面端内置 DeepSeek、OpenAI、Anthropic、Gemini、xAI、Mistral、Groq、阿里云百炼、硅基流动、OpenRouter、Together、Kimi、智谱、MiniMax、NVIDIA NIM 和自定义 OpenAI 兼容接口；模型从厂家接口实时读取。
- 按歌曲累计 AI token 与估算费用；可导出不含 API Key、音频和歌词正文的 `.uta-analysis` 共享解析，其他用户已有同一歌词时可直接复用。
- 学习进度、读音修正、手工词义和网页导入歌曲都保存于浏览器本地。
- 可从歌曲库导出单个本地备份文件，并在另一浏览器恢复歌曲、音频、读音修正与学习进度。
- 内置日漫抒情风格主页和独立歌曲库；可按歌名或歌手检索、切换歌曲，并删除网页导入的歌曲。
- 启动默认进入歌曲库；没有歌曲时可导入第一首歌，或单独体验无音频示例。顶部问号可重新打开使用引导。
- 导入时按歌名和歌手尝试匹配 Apple Music 封面；未找到可靠结果时使用默认封面。

## 效果预览

启动后访问 `http://localhost:5173`，可先用仓库内的原创短句练习，也可在“歌曲库”使用“导入歌曲”选择一份 `.lrc` 与对应音频文件。内置示例不附带音频，播放按钮会保持禁用；需要试听和慢放时请导入自己的音频。

在项目根目录打开 PowerShell：

```powershell

# 2. 创建项目内的 Python 虚拟环境
py -3 -m venv server\.venv

# 4. 同时启动网页与本地标注 API
npm.cmd run dev
```

打开：

- 网页：`http://localhost:5173`
- 本地 API：`http://127.0.0.1:8000`

生产构建校验：

```powershell
npm.cmd run build

server\.venv\Scripts\python.exe -m unittest discover -s server\tests
```

所有 npm 依赖放在项目的 `node_modules/`，Python 依赖放在 `server/.venv/`，不会安装到系统全局目录。

## Windows 桌面端

桌面端采用 Electron 窗口加 PyInstaller Python sidecar，并由 electron-builder 生成安装包。安装包内自带 Chromium、Python 运行时、SudachiPy 和核心词典，最终用户不需要单独安装 Node.js 或 Python；网页导入的歌曲和学习记录仍保存在应用自己的本地数据目录。

首次在独立 Python 虚拟环境中安装桌面构建依赖：

```powershell
python -m venv server\.venv
server\.venv\Scripts\python.exe -m pip install -r server\requirements-build.txt
npm.cmd ci
```

开发模式会启动 Vite、Electron 与虚拟环境中的本地 API：

```powershell
npm.cmd run desktop:dev
```

生成 Windows x64 安装包：

```powershell
npm.cmd run desktop:make
```

安装包输出到 `out/UTA-Setup-<版本>.exe`。构建过程先生成 Vite 静态文件，再把 FastAPI、SudachiPy 与静态文件冻结为 `uta-backend.exe`，最后由 electron-builder 生成 NSIS 安装包。`desktop/backend-build/`、`desktop/backend-dist/` 与 `out/` 都是可删除的本地构建产物，不会提交到 Git。

桌面端使用固定的本机地址 `http://127.0.0.1:14731`，只监听回环接口；Electron 负责启动和退出本地服务，并限制渲染进程访问 Node.js。点击右上角齿轮后选择 AI 供应商、粘贴 Key 并选择模型即可；无需给 Key 命名，应用自动编号，多个 Key 可选择或删除。模型地址与人民币参考价格自动填写，详情默认折叠。密钥由 Windows DPAPI 使用当前账户加密保护；旧明文 Key 自动迁移。设置保存在 `%APPDATA%\UTA\ai-settings.json`，不会进入浏览器存储、备份或共享文件。可选 Tomoshi 词典也在同一设置窗口管理，安装到 `%APPDATA%\UTA\data\tomoshi-dict-open.db`。不要把 API Key 或本地词典加入安装包或仓库。

当前桌面端面向 Windows x64，已内置统一的 PNG / 多尺寸 `.ico` 应用图标。正式对外发布前仍需准备 Windows 代码签名证书，以减少 SmartScreen 拦截；当前本机验收构建不代表已完成发行签名。

只生成便携验收版（不创建安装包）可执行 `npm.cmd run desktop:package`，然后双击根目录的 `启动最新验收版.cmd`，或运行 `out/win-unpacked/UTA.exe`。重新打包前请退出旧版应用，避免文件被占用。

### 以后不用输入命令

首次完成上述安装后，直接双击项目根目录的 [启动 UTA 网站.cmd](启动%20UTA%20网站.cmd)。它会启动本地服务并自动打开浏览器。不要关闭标题为 `UTA local server` 的命令窗口；关闭它即可停止网站。

## 逐句练习与复习

在“发音学习”页面点击“开始逐句练习”。练习卡片先只显示日文原句；可以播放该句原声并调整速度，尝试自己读出、理解后，再点击“揭晓读音与译文”。网站不会自动判定唱得是否正确，由学习者对照答案选择“我会了”或“还要再练”。

“我会了”会更新这首歌的掌握进度；“还要再练”会将该句加入复习清单。点击页眉“复习”可查看所有待复习句，点击任意一项可从该句开始练；练会后会自动移出清单。没有音频时仍可练习读音和词义，但揭晓读音需要本地标注服务运行。

## 网页导入自己的歌曲

1. 在“歌曲库”点击 **导入歌曲**。
2. 选择一个包含逐句时间戳的 `.lrc` 文件。
3. 选择对应的音频文件（MP3、M4A、WAV、OGG、WebM 等）。
4. 等待歌词解析和封面查找，检查预览中的歌名、歌手、逐句日文、中文译文及时间戳；需要时可直接修改、添加或删除句子。封面不正确时可重新查找、填写图片链接，或使用默认封面。
5. 点击 **保存并开始学习**。歌词与音频保存在本机，导入不调用 AI；学习页可另行生成 AI 解析。

导入的歌词数据和音频保存在当前浏览器的 IndexedDB：刷新页面后仍可使用，但换浏览器、清除站点数据或清除浏览器存储后会消失。不会按原文件路径读取，也不会将音频文件上传到远程服务器。歌词文本会发送给本机 FastAPI 服务生成读音；保存导入不会调用 AI，只有主动生成解析或复核时才向所选 AI 供应商发送必要上下文并可能产生费用。导入时，为查找封面，歌曲名和歌手名会经本地服务发送给 Apple Music；详见下方“隐私与数据”。

LRC 的每句应带有时间戳，例如：

```lrc
[00:12.40]夏の空を見上げる
[00:16.20]仰望夏日的天空
[00:16.20]君に言葉を届けたい
[00:20.50]想把话语传达给你
```

中文译文放在对应日文歌词的下一行即可；即使译文的时间戳与下一句日文相同，也会按相邻顺序配对。只有日文的 LRC 也能导入，只是不显示中文释义。旧版已导入的歌曲若没有译文，需要用原 LRC 和音频重新导入一次。

LRC 中的歌名、歌手资料行不会作为歌词参与读音标注或 AI 全曲复核；歌曲正文里单独出现的同名歌词仍会保留。已经导入的旧歌曲无需重新导入，页面会自动隐藏这些资料行。

每句歌词右侧播放和掌握按钮下方的 **查看解析**，会在当前句下方展开已缓存的整句 AI 讲解；再次点击即可收起，逐句练习时也可在答案下方展开。若 AI 未配置、限流或中途失败，歌曲仍会保存；学习页可点击 **生成剩余解析** 续做。以前导入的歌曲和项目内置歌曲也可在学习页主动批量生成；尚未缓存的单句可以点击 **生成解析**。缓存只对原句相同的歌词有效，选中某个词或片段的现有 AI 讲解仍是按需请求。

## 数据备份与恢复

在“歌曲库”点击 **导出备份**，浏览器会下载一个 `.uta-backup` 文件。它包含网页导入歌曲的歌词、原声音频、歌曲资料，以及已掌握句子、复习清单、收藏、读音与词义修正、自动注音缓存、AI 复核记录和已生成的整句解析；内置歌曲的歌词与音频仍由项目本身提供。备份只在本机浏览器生成，不会上传到服务器。

换浏览器或清除站点数据前，请先保存这个文件。需要恢复时，在“歌曲库”点击 **恢复备份** 并选择文件，检查预览后确认。恢复会**覆盖当前浏览器**里已有的网页导入歌曲和学习记录，不会把两份数据合并；因此建议恢复前先导出当前数据。恢复完成后页面会自动刷新。备份包含原声音频，请妥善保管，不要在没有授权的情况下分享或公开发布。

### 共享 AI 解析

学习页的 **导出解析** 会下载 `.uta-analysis` 文件。文件只包含歌名、歌手、歌词句子的 SHA-256 指纹、AI 解析和费用来源记录，不包含歌词正文、音频或 API Key。接收者先在自己的歌曲库中导入同一份歌词，再于歌曲库点击 **导入共享解析**；只有指纹匹配的句子会合并，因此无需再次付费生成。导入别人的解析不会计入本机 AI 花费。

AI 解析本身可能引用少量歌词词语；分享前仍应确认你有权传播相关内容。完整 `.uta-backup` 含歌词与原声音频，只适合个人迁移，不应作为公开共享格式。

## 向项目内置歌曲库增加歌曲

适合在自己的本地开发环境维护歌曲库：

1. 把 `.lrc` 文件放进 `geci/`。
2. 把同名音频文件放进 `song/`，例如 `歌手-歌名.lrc` 对应 `歌手-歌名.mp3`。
3. 执行：

   ```powershell
   npm.cmd run lyrics:sync
   ```

脚本会生成 `src/data/songs.generated.js`。不要手工编辑这个生成文件。为避免意外公开受版权保护的歌词和音频，`geci/`、`song/` 和生成的歌曲数据默认不会提交到 Git。

内置歌曲和网页导入歌曲会尝试按歌名、歌手搜索封面；如需为内置歌曲指定封面，可在 `src/data/songArtwork.js` 中按 `sourceFile` 配置公开封面 URL 与来源页链接。专辑封面通常受版权保护。

## 本地完整日中词典（可选，但推荐）

项目不提交体积较大的解压词典数据库（当前版本约 650 MB，随上游版本变化）。没有它时仍能自动注音，但可显示的中文释义会较少。

桌面端首次启动会先询问是否安装。选择 **下载并安装** 后，应用会显示浮动进度窗，从 Tomoshi 的 GitHub Releases 自动下载、解压并校验；可随时取消，已下载部分会保留，稍后继续时支持续传。首次跳过后可点击右上角齿轮，在 **设置 → 本地词典** 下载推荐词典、打开发布页，或上传 `.db.zst`、`.db`、`.sqlite`、`.sqlite3` 文件。未压缩 SQLite 必须包含 `entries`、`forms`、`zh_defs` 三张表，其他格式不会被导入。

若 GitHub 下载较慢或无法连接：

1. 用浏览器打开 [Tomoshi Dictionary Open Data Layer 发布页](https://github.com/tomoshi-app/tomoshi-dict-data/releases)，下载最新版本的 `tomoshi-dict-open.db.zst`；可以使用浏览器自身的断点续传、代理或可信的下载工具。
2. 回到桌面端，点击右上角齿轮，选择 **本地词典 → 上传本地词典**。
3. 应用会在本机解压并检查必要的数据表；成功后压缩包可以自行保留或删除。

网页开发版仍可按以下步骤手工安装：

1. 从 [Tomoshi Dictionary Open Data Layer 的发布页](https://github.com/tomoshi-app/tomoshi-dict-data/releases) 下载 `tomoshi-dict-open.db.zst`。
2. 放到 `server/data/tomoshi-dict-open.db.zst`。
3. 在 `server/` 目录执行：

   ```powershell
   @'
   from pathlib import Path
   import zstandard as zstd

   source = Path('data/tomoshi-dict-open.db.zst')
   target = Path('data/tomoshi-dict-open.db')
   with source.open('rb') as reader, target.open('xb') as writer:
       zstd.ZstdDecompressor().copy_stream(reader, writer)
   '@ | .\.venv\Scripts\python.exe -
   ```

首次查询会使用该本地 SQLite 数据库；不会把歌词或查词内容发送给词典服务。公开部署、修改或重新分发词典数据时，请遵守 [THIRD_PARTY_DATA_NOTICES.md](THIRD_PARTY_DATA_NOTICES.md) 中的署名与许可要求。

## 可选：启用 AI 解析与复核

### 歌词时间轴与学习进度

当前导入需要同一版本的 `.lrc` 和音频。LRC 是带时间戳的歌词文本，例如 `[00:12.50]ここから始めよう` 表示该句从 12.5 秒开始；它不含音频。可以在 [LRCLIB](https://lrclib.net) 查找同步歌词，使用支持导出 LRC 的播放器，或自己用歌词编辑器打时间戳。仅修改 TXT 后缀不会产生时间轴；现场版、剪辑版需核对时间。导入窗口提供折叠的获取说明。

歌曲库只展示已完成歌曲数和歌曲总数，不含体验示例；全部有效歌词句均标记掌握时，歌曲计为完成，卡片只显示完成状态。学习页保留本曲已掌握比例、句数和待复习数，并可展开逐句状态点击跳转。进度依据你手动标记或练习中的“我会了”，不是 AI 评分。普通控件字号为 16px，辅助说明为 14px，歌词为 26px（小屏 23px）。词典安装完成后进度浮窗自动关闭，词典状态仍可在设置中查看。界面采用圆角、柔和悬浮阴影和轻量切页动画；系统选择减少动态效果时会停用动画。

复习采用“列表 → 本曲复习练习 → 返回列表”的独立流程，练习期间保持“复习”导航高亮。点击某句会从该句开始，之后继续本曲其他待复习句，不遗漏之前的条目；退出返回复习列表。切换到歌曲库或复习列表会停止播放并退出旧练习。界面使用本机安装的中日文字体，不再依赖在线字体下载。

点击词语后，词典和 AI 语境详情展示在不遮挡歌词的右侧栏，小屏改为底部面板。设置中的“阅读与字号”可分别调整界面字号（14–22px）和歌词字号（20–40px），即时生效并自动保存在本机；恢复默认不修改 API Key。正文、导航和标题采用统一的系统无衬线字体。卡片悬浮包含轻微上浮和封面缩放，切页使用 380ms 淡入与位移动画；系统减少动态效果设置仍优先。

当前未接入 mp3.org.cn 等第三方站点的自动音频下载：其搜索跳转到外站，尚未验证稳定可用的音频和 LRC 下载接口。不要把网页搜索入口当成已有的自动导入功能。

动态效果可选择“开启 / 跟随系统 / 关闭”，设置中展示系统减少动态效果状态并提供预览；选择“开启”明确使用应用动画。歌曲完成统计采用完成环。新生成的注音会合并常见月份表达（例如 `4月 → しがつ`），不将 `4か月` 当作四月。遇到其他分词错误，点击词或拖选相邻词，在右侧“调整分词”中每行填写一个词：删除换行合并，增加换行拆分。原文必须完全一致，包括空格和标点；有效修改会自动重新查询本地词典并显示预览，确认后保存。也可以选择整句，让设置中的 AI 模型结合语境检查边界，再确认建议；AI 调用费用记入歌曲费用，手动查词免费。未命中词典时明确提示，不把 AI 猜测当词典释义；读音仍可能需要人工校对。未改变边界的人工读音保留，当前会话支持撤销上一次分词修改，原歌词不变。

默认读音完全由本地 SudachiPy 生成。导入并保存歌曲不会调用 AI；点击“生成剩余解析”“生成解析”“AI 复核全曲”或片段的“AI 解释”时，才会向选定供应商发送必要的歌词上下文。学习页默认聚焦逐句听读，“校对读音”按需展开侧栏，批量 AI 操作和解析导出位于折叠的“AI 与共享工具”。

桌面端点击右上角齿轮：

1. 从内置主流厂家列表中选择供应商；只有“其他 OpenAI 兼容接口”需要填写自定义地址。
2. 无需 API Key 即可浏览 Models.dev 按供应商整理的公开注册表；社区资料不代表账号权限。默认显示最多六个常用模型及当前选项，仅显示简洁名称；“全部模型”可展开搜索。粘贴 Key 无需命名，应用自动编号，已保存的 Key 仍可切换或删除。填写 Key 后点击 **刷新**，应用通过厂家接口核对账号模型列表。
3. 价格与接口 ID、地址、来源和读取时间放在“价格与连接详情”。价格优先读取厂家接口，其次使用 Models.dev 社区参考价格，缺失时用 LiteLLM 目录补齐，再按欧洲央行参考汇率折算人民币。无需手工填写；聚合平台模型 ID 不会被直接转换为厂家 ID。
4. 保存后，每次 AI 请求会记录供应商返回的 token 用量，并在歌曲页以人民币显示累计估算费用。价格目录、汇率和厂家计费规则都可能变化，因此页面数值用于比较成本，不是付款凭证，最终以供应商账单为准。

网页开发版仍兼容原有 DeepSeek `.env` 配置：

在 `server/` 下复制 `.env.example` 为 `.env`：

```powershell
Copy-Item server\.env.example server\.env
```

编辑 `server/.env`：

```ini
DEEPSEEK_API_KEY=你的 DeepSeek API Key
DEEPSEEK_MODEL=deepseek-flash
```

`.env` 已被 Git 忽略，绝不要把 API Key 写进前端代码、截图或公开仓库。

## 隐私与数据

| 内容 | 保存位置 | 是否上传 |
| --- | --- | --- |
| 学习进度、读音与词义修正 | 浏览器 Local Storage | 否 |
| 网页导入的 LRC 与音频 | 浏览器 IndexedDB | 否 |
| 自动注音、词典释义 | 本机 FastAPI 服务 | 否 |
| 封面检索所需的歌名、歌手名 | 本机 FastAPI 服务转发给 Apple Music | 是，仅导入或补查封面时 |
| AI 整句解析 / 复核 / 片段讲解 | 用户选择的 AI 供应商（主动点击生成后） | 会发送所需歌词上下文与已有译文；不会发送音频 |
